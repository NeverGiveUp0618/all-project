独立入口：`https://nevergiveup0618.github.io/all-project/luopan/`。导航卡片在杨公背诵前，杨公背诵源码不改。

## 当前范围

- 转盘页以用户提供的“精密罗盘指南针 · 二十九层综合盘”两张截图为视觉底稿。保留原盘层序、字形、盘色、红底、前向后坐、天池及十字线；不是先前另排的15层示意盘。
- 盘面可单指/鼠标转动，双指缩放移动、滚轮缩放，锁定方向，输入度数；放大后可切换拖动移动。长按环带查看说明。实景按钮选择本机照片作背景，不上传照片。
- 手动学习模拟，不调用磁力计、GPS，也不把固定水平尺示意伪装成真实倾角。首页“手动学习”与设置页明确说明。没有仿造手机时钟、电量或信号。
- 15项常用知识解释与原盘观察，包括三盘、正体/双山/三元龙、八卦、分金等；**15项知识主题不等于原软件29层名称已全部逐字录入**。同款盘的细字保留在原图中，不能拿另一张表的计算结果冒充当前压字。仅地盘/人盘/天盘山字及周天度数输出直接读数，其他按原盘局部目读；逻辑分类明确注明按地盘山字归类。
- 八篇读盘小课，默认折叠；175道客观练习（转盘定位24、度数认山24、坐向24、正体24、双山24、三元24、对象报读与分格7、三盘沿线读格24）。一次一题、手动下一题。转盘定位练习使用字大的二十四山简图；原盘回查一直打开二十九层原盘。
- 错题自动保存、按知识点筛选、回盘定位、到期复习、两组连续答对订正；刷新或回盘可继续原题。共享笔记、导航时长、看板、自检、备份与进度镜像已对接。

## 学习安排

先四正四隅 → 二十四山与15° → 非中心度数和山界 → 坐与向 → 正体/双山分类 → 对象报读 → 细层目读。每日八题先尝试回想，答后解释，不限时；错误项和到期项优先。网站内另有纸上默画、实体罗盘测量后输入度数复核的练法，不承诺固定天数掌握全部理气用法。

检索练习和间隔复习的一般依据：[Karpicke & Roediger 2008](https://doi.org/10.1126/science.1152408)、[Karpicke & Bauernschmidt 2011](https://pubmed.ncbi.nlm.nih.gov/21574747/)。具体八题和复习间隔是本工具的设计，不是上述研究规定的课表。
