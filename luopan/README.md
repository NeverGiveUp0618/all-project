# 罗盘学习

易术堂的独立模块，导航入口固定在杨公背诵前。线上地址：
https://nevergiveup0618.github.io/all-project/luopan/

## 当前实现

- 界面采用易术堂深蓝、青色和古金配色，去掉仿应用红底、水平仪和实景按钮；盘面保留原盘黄底及红绿蓝色环带。
- 全盘、局部和练习盘均由SVG文字、路径、刻线绘制，没有截图纹理、canvas位图或嵌入字体。支持12倍放大、拖转、移动、输入度数、快速选山和选层。
- 已对照运行中的精密罗盘指南针3.5.2读取罗层名称、顺序与高度，并核对原盘基础文字表。盘名沿用“二十九层综合盘”；该版本实际罗层菜单为第1层天池至第28层360度，即天池加27环带，按软件实际显示，不补造一层。共2934个角度分格。
- 盘面包含三盘二十四山、72龙、两圈120分金、透地60龙、三七正位、方圆两套64卦、父母三般卦、卦运方向、384点格、时宪宿度、盈缩61分位、开禧宿度及星度数/标记/五行。
- 原175题、稳定ID、错题、手动下一题、刷新续做和全科笔记保留。知识归类选项与实物盘层分开，四种归类不当成原盘额外四层。

矢量化解决像素模糊和截图拼接重影。当前字形采用设备系统中文字体，天池装饰与极窄宿格符号以矢量近似绘制，不能声称第三方字体和每个装饰笔画逐像素相同。盘面是学习模拟，不读取手机磁力计。

- 原有示意表来自用户本地罗盘项目的事实数组，独立于目标软件29层。不能把另一种盘式的72龙、分金、卦爻或宿度表当作同款的逐格答案。
- 本门测山水用地盘；正体、双山、三元分类分别讲解。纳甲配卦与纳甲阴阳的原文有异文，不合成唯一阴阳答案。三盘沿线题与高级表用法的范围不混淆。

## 触控与流畅度

单指始终旋转（含放大与看清本层后），双指移动并缩放。双指松开一指后，需全部松手再开始单指旋转，避免跳盘。指针事件合并到浏览器动画帧。全盘1倍时使用HTML独立合成层旋转；超过1倍改由SVG内部几何变换进行放大和旋转，并关闭盘面容器的纹理提升，避免放大低分辨率合成缓存。红线另层绘制；相同的变换不重复写入。放大模式优先保证当前倍率的文字清晰度，不承诺与1倍相同的帧率。手势开始时缓存几何尺寸，移动时不反复读取布局；起动阈值降至0.5像素，慢转一度也能跟手。当前角度实时显示在盘面下方；松手后统一刷新完整读数、讲解与保存位置，跨格不重建局部矢量文字。

“罗层显示”按钮可开关天池及27圈，默认全部显示；提供全部显示、全部隐藏和只看三盘与度数。隐藏后保留原圈位置，不挤动其他层。设置存于原记录键的`view.hiddenLayers`，刷新和进度备份可保留，原题目记录不变。主动选择或放大隐藏层时会显示该圈；其他隐藏圈不变，练习图独立显示。
